# notes-algebraic-geometry

Personal study notes on algebraic geometry — from graduate coursework and research at USTC.

## Contents

- **Vector bundles** — Stability, Chern classes, Bogomolov inequality
- **Surfaces** — Quasi-elliptic surfaces, ruled surfaces, classification
- **Characteristic p geometry** — Pathologies and differences from characteristic 0
- **Hodge theory** — de Rham cohomology, Hodge decomposition

## Related work

- *Bogomolov Type Inequality on Quasi-Elliptic Surfaces* — published in *Journal of Mathematics (数学杂志)*, 2025. MSC: 14J60, 14J26.

## References

- Hartshorne, *Algebraic Geometry*
- Lazarsfeld, *Positivity in Algebraic Geometry* (vols. I–II)
- Kollár–Mori, *Birational Geometry of Algebraic Varieties*
