# notes-algebraic-geometry

Study notes from graduate work in algebraic geometry at USTC (2023–2026).

Topics:
- Vector bundles: Chern classes, stability, Bogomolov inequality
- Quasi-elliptic surfaces in characteristic p
- Ruled and rational surfaces, classification of surfaces
- Coherent sheaves, intersection theory

Published work: *Bogomolov Type Inequality on Quasi-Elliptic Surfaces*, Journal of Mathematics (数学杂志), 2025. MSC: 14J60, 14J26.

References used: Hartshorne, Lazarsfeld (*Positivity in Algebraic Geometry* I–II), Kollár–Mori.
